# 🚀 Render Cloud Deployment Guide for Smart Bus System

Follow these steps to deploy the **Smart Bus Complaint & Monitoring System** on Render.

## 🔗 Step 1: Open Render Blueprint Deploy
Click this link to start 1-click deployment on Render:
👉 **[Deploy to Render](https://render.com/deploy?repo=https://github.com/Thamizhselvans-tech/busgp)**

---

## ⚙️ Step 2: Configure Environment Variables

Render will automatically detect `render.yaml` and create two services:
1. `smart-bus-backend` (Node.js API Server)
2. `smart-bus-frontend` (React Static Web Application)

### Environment Variable Settings:
- **`MONGODB_URI`**: Set your MongoDB Atlas connection string:
  ```
  mongodb+srv://admin:password123@cluster0.mongodb.net/smart-bus?retryWrites=true&w=majority
  ```
- **`JWT_SECRET`**: (Auto-generated by Render blueprint or enter your secret key)
- **`NODE_ENV`**: `production`

---

## 🎯 Step 3: Deployment Verification

Once Render finishes building:
- **Backend Service**: `https://smart-bus-backend.onrender.com`
- **Frontend Web App**: `https://smart-bus-frontend.onrender.com`

---

## 📱 Mobile App Connection
In `mobile/src/config/api.ts`, update `API_BASE`:
```ts
export const API_BASE = 'https://smart-bus-backend.onrender.com/api';
```
